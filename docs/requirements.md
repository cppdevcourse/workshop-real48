# Требования

## Общие требования к классу `Real48`

1. Размер объекта `Real48` должен составлять 6 байт.

2. Объект должен представлять в памяти число с плавающей точкой
   так же, как делает это Delphi.
   Т.е., должна быть возможность выполнить `memcpy` из
   объекта в сетевой пакет, отправить это программе на Delphi, и
   последняя должна корректно десериализовать число с плавающей точкой.

## Конструктор по-умолчанию

```cpp
constexpr Real48();
```

Конструктор по-умолчанию должен создавать число с плавающей
точкой со специальным значением ноль.

## Конструкторы из `float` и `double`

```cpp
Real48(const float number);
Real48(const double number);
```

1. Если параметр является NaN или бесконечностью, то
   конструктор должен выбрасывать `std::overflow_error`.

2. Если параметр является нулем или ненормализованным числом,
   то конструктор должен создавать число с плавающей
   точкой со специальным значением ноль.

3. Если параметр является нормализованным числом, но не может
   быть корректно представлен в `Real48` (например, слишком
   большое $e$, не помещающееся в 8 бит), то конструктор
   должен выбрасывать `std::overflow_error`.

4. Если не удалось определить тип параметра (NaN, бесконечность,
   ненормализованное число, ноль, нормализованное число), то конструктор
   должен выбрасывать `std::overflow_error`.

5. Если параметр $F$ является нормализованным числом и может быть
   представлен в `Real48`, то должно формироваться
   число с плавающей точкой по формуле из
   [описания проблемы](problem.md):

   $$F = \left(-1\right)^s \cdot 2^{e - 129} \cdot \left(1 + \frac{f}{2^{39}}\right)$$

   Можно считать, что `float` и `double`
   закодированы стандартом IEEE~754 в little-endian архитектуре.
   Например, для перевода из `double` можно составить
   следующее равенство:

   $$\begin{split}
     F = \left(-1\right)^{s_{48}} \cdot 2^{e_{48} - 129} \cdot \left(1 + \frac{f_{48}}{2^{39}}\right) = \\
       \left(-1\right)^{s_{64}} \cdot 2^{e_{64} - 1023} \cdot \left(1 + \frac{f_{64}}{2^{52}}\right)
   \end{split}$$

   где $s_{48}$, $e_{48}$ и $f_{48}$ — искомые параметры
   `Real48`, а $s_{64}$, $e_{64}$ и $f_{64}$ — известные параметры
   `double`.

## Операторы приведения к `float` и `double`

```cpp
operator float() const;
operator double() const noexcept;
```

1. Операторы приведения должны выполнять обратное преобразование по
   отношению к преобразованиям, производимым конструкторами.
   Например, для перевода в `double` можно воспользоваться
   равенством из раздела
   «[Конструкторы из `float` и `double`](#конструкторы-из-float-и-double)».

2. Оператор приведения к `float` должен выбрасывать
   `std::overflow_error`, если объект `Real48`
   не может быть представлен в `float`.

## Операторы присваивания

```cpp
Real48& operator+=(const Real48& b);
Real48& operator-=(const Real48& b);
Real48& operator*=(const Real48& b);
Real48& operator/=(const Real48& b);
```

Поведение операторов присваивания должно учитывать арифметику
плавающих чисел.
Допустимо использовать арифметику плавающего числа другого типа.

## Арифметические операторы

```cpp
Real48 operator+() const noexcept;
Real48 operator-() const noexcept;
Real48 operator+(const Real48& o) const;
Real48 operator-(const Real48& o) const;
Real48 operator*(const Real48& o) const;
Real48 operator/(const Real48& o) const;
```

Поведение арифметических операторов должно учитывать арифметику
плавающих чисел.
Допустимо использовать арифметику плавающего числа другого типа.

## Операторы сравнения

```cpp
bool operator>(const Real48& o) const noexcept;
bool operator<(const Real48& o) const noexcept;
```

Поведение операторов сравнения должно учитывать арифметику
плавающих чисел.
Допустимо использовать арифметику плавающего числа другого типа.

## Метод `Classify`

```cpp
enum class Class
{
    NORMAL,
    ZERO
};
Class Classify() const noexcept;
```

Этот метод должен возвращать `Class::ZERO`, если
число имеет специальное значение ноль, и `Class::NORMAL`
в ином случае.

## Метод `min`

```cpp
consteval static Real48 min();
```

Метод должен возвращать минимальное положительное значение, которое возможно
представить в `Real48`, отличное от нуля.

## Метод `max`

```cpp
consteval static Real48 max();
```

Метод должен возвращать максимальное положительное значение, которое возможно
представить в `Real48`.

## Метод `epsilon`

```cpp
consteval static Real48 epsilon();
```

Метод должен возвращать разницу[^1] между 1.0 и следующим значением,
которое можно представить в `Real48`, в нормализованном виде.
Для `Real48` это число — $2^{-39}$.

[^1]: <https://en.wikipedia.org/wiki/Machine_epsilon>
